# AsiBackbone Support and Question Routing

AsiBackbone projects are community-maintained open-source resources. Support is provided on a best-effort basis without a service-level agreement or guaranteed response time.

## Project-Specific Help

Keep questions with the repository that owns the affected implementation:

- [Learning Discussions](https://github.com/AsiBackbone/Learning/discussions) for tutorials, labs, samples, and learning material;
- [AsiBackbone Discussions](https://github.com/AsiBackbone/AsiBackbone/discussions) for framework packages, APIs, integration, and runtime behavior; and
- [.NET Core Application Template Discussions](https://github.com/AsiBackbone/NetCoreApplicationTemplate/discussions) for template setup, generated applications, packaging, and extension guidance.

Use that repository's issue tracker for a reproducible defect or clearly scoped work item. Read its support and contribution guidance first because repository-specific policies are authoritative.

## Organization-Wide Questions and Proposals

Use [AsiBackbone organization Discussions](https://github.com/orgs/AsiBackbone/discussions) only when a topic genuinely spans projects or concerns the organization as a whole:

- [Q&A](https://github.com/orgs/AsiBackbone/discussions/categories/q-a) for cross-project questions;
- [Ideas](https://github.com/orgs/AsiBackbone/discussions/categories/ideas) for proposals; and
- [Architecture & Integration](https://github.com/orgs/AsiBackbone/discussions/categories/architecture-integration) for cross-project design and integration discussion.

## Security and Sensitive Information

Do not disclose passwords, tokens, personal data, exploit details, or other sensitive material in public issues or Discussions. Follow the affected repository's private process described in the [security reporting guidance](SECURITY.md).

These projects provide practical engineering resources. They do not provide private consulting, production incident response, legal advice, compliance certification, or automatic security assurance.
