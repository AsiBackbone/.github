# AsiBackbone

**Enterprise .NET reference architectures for secure-by-default applications,
policy governance, auditability, and compliance-oriented systems.**

AsiBackbone develops open-source .NET architecture and governance tools for
secure application development, AI governance, policy-as-code, auditable
decision systems, capability-based authorization, zero-trust execution, and
enterprise ASP.NET Core development.

## Projects

### [ASI Backbone](https://github.com/AsiBackbone/AsiBackbone)

A .NET governance and policy-control framework for building auditable,
policy-governed decision pipelines.

Key areas include:

- Policy evaluation and policy-as-code
- AI and application governance
- Auditable decision records
- Acknowledgment workflows
- Capability-based authorization
- Zero-trust execution boundaries
- ASP.NET Core integration

- [**Explore ASI Backbone Repository**](https://github.com/AsiBackbone/AsiBackbone)
- [**ASI Backbone Documentation**](https://asibackbone.github.io/AsiBackbone/)

### [.NET Core Application Template](https://github.com/AsiBackbone/NetCoreApplicationTemplate)

A secure-by-default ASP.NET Core enterprise application template for building
maintainable, production-ready .NET applications.

Key areas include:

- ASP.NET Core
- Authentication and authorization
- Serilog structured logging
- Security headers
- Rate limiting
- EF Core
- SQL Server and SQLite
- Reverse proxy support
- Problem Details and centralized error handling

- [**Explore .NET Core Application Template Repository**](https://github.com/AsiBackbone/NetCoreApplicationTemplate)
- [**.NET Core Application Template Documentation**](https://asibackbone.github.io/NetCoreApplicationTemplate)

## Design Philosophy

We favor architectures where consequential operations are explicit,
constrained, reviewable, and auditable.

Our projects focus on practical .NET engineering rather than claiming
regulatory certification or automatic compliance.
